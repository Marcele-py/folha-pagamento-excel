Planilha de folha de pagamento desenvolvida em Excel, com foco no cadastro de funcionários, cálculos automáticos de salários e análise dos custos da folha.

O projeto possui uma aba para cadastro de dados dos funcionários (tipo de contrato, cargo, departamento, salário bruto e valor de hora extra) e outra aba para os cálculos da folha, incluindo INSS, Imposto de Renda, vale-transporte, horas extras, outros descontos e salário líquido. 

Foram utilizadas funções como PROCV, SE, soma, subtração e multiplicação, além de tabelas dinâmicas, gráficos e um dashboard com análises de gastos e evolução salarial.
Todos os dados utilizados nessa planilha são fictícios, não possui quaisquer dados sensíveis.
